# Python Sprint 28 jours

Sprint de 28 jours pour apprendre Python de zéro, sur téléphone (Pydroid 3).
Un concept par jour, deux exercices, des notes à la fin de chaque jour. À la fin de chaque semaine, un examen qui regroupe les concepts vus en cours de semaine.

## Ma méthode

- Prédire la sortie avant de lancer le code
- Suivre les variables à la main, tour par tour
- Vérifier une checklist avant chaque envoi : aucune valeur en dur,
  format de sortie exact, noms clairs, calculs avant l'affichage
